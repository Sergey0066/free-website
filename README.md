# free-website

Бесплатный сайт для вашего проекта или любого другого дела.

## О проекте
Этот проект представляет собой готовую вёрстку сайта для бизнеса.
Макет сайта был создан в Figma, после чего перенесён в HTML/CSS/JS.

## Особенности

- Адаптивная вёрстка.
- Подходит для бизнес-сайта или лендинга.
- Создано по шаблону из Figma.
- Чистая структура исходников.
- Подходит для дальнейшей доработки под ваш бренд.

## Для чего подойдёт

Этот шаблон можно использовать для:

- сайта компании;
- лендинга услуг;
- презентации бизнеса;
- персонализации под клиента;
- быстрого старта нового веб-проекта.
