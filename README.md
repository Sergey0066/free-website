# free-website

Бесплатный сайт в виде вёрстки для вашего бизнеса.

## О проекте

Этот проект представляет собой готовую вёрстку сайта для бизнеса.  
Макет сайта был создан в Figma, после чего перенесён в HTML/CSS/JS.

## Как запустить

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/USERNAME/free-website.git
   ```

2. Перейдите в папку проекта:
   ```bash
   cd free-website
   ```

3. Откройте файл `index.html` в браузере.
